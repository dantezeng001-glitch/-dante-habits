# NT 北美上市复盘分析大文档

## 文档结构

输出为单个 Markdown 文件，放在工作区根目录：`NT上市复盘-策略分析完整版.md`

### 章节规划（8 章）

**第一章：项目概况**
- 产品定位、定价、目标人群、卖点排序、竞品对标
- 营销三目标（拓圈/心智/上量）
- 渠道策略和上市节奏时间线
- 数据来源：`OpenFit Pro北美上市营销方案书.md` 中的项目背景、产品 Message House、操盘策略部分

**第二章：各模块首销数据总览**
- 曝光/预算/占比总表（KOL 4.87M / Social 1.2M / PR 12.3M / DM / Event 3.6M）
- 官网销量与目标达成（US 5672/189%, CA 428/214%）
- 亚马逊首 10 天数据（1875 台/ROAS 5.85）
- 与历代产品对比表
- 数据来源：`NT上市首月阶段性效果复盘.md`、`NT亚马逊上市首周反馈.md`

**第三章：上游心智建设板块分析（技术发布会 + KOL + PR）**
- 每个板块：策略意图 / 策略合理性 / 执行优势 / 劣势与风险 / 优化建议
- 数据来源：Agent 1 分析结果 + 原始文档交叉验证

**第四章：中游转化承接板块分析（DM 广告 + 官网 + 亚马逊）**
- 同上结构
- 数据来源：Agent 2 分析结果 + 原始文档交叉验证

**第五章：下游内容与口碑板块分析（社媒 + 社群/Reddit + PMKT 素材）**
- 同上结构
- 数据来源：Agent 3 分析结果 + 原始文档交叉验证

**第六章：VOC 与用户画像洞察**
- 用户画像（年龄/收入/性别/购买动机）
- 滤噪作为核心购买驱动力的验证
- 全渠道 VOC 亮暗点汇总表
- 场景替代率数据
- 数据来源：`NT 北美上市后报告.md`、`NT上市首月阶段性效果复盘.md` 中的 VOC 部分

**第七章：跨板块结构性发现（5 条）**
- 人群策略与渠道执行错位
- 上游种草深度 vs 中游承接能力断层
- "场景多元"假设被数据半否定
- NR vs ANC 叙事框架的两层效果
- 时间节奏的两个断层
- 来源：跨板块汇总分析

**第八章：数据核查与修正记录**
- 62 条声明核查结果摘要（59 准确 / 2 偏差 / 1 推断）
- 3 条修正的具体内容和理由
- 来源：核查 Agent 结果 + 修正内容

### 写作原则

- 用途是个人留底，写法偏**工作笔记**而非正式报告：保留判断密度，不加套话和开场白
- 数据直接用表格呈现，分析用 bullet 精简表达
- 已修正的 3 处偏差在正文中直接使用修正后的版本，不保留错误版本
- 章节间不重复同一个数据点（表格承载的不用段落复述）
