# 修复 Skills 透视无法关闭

## 问题根因

`skillsView.show()` 把 `state.skillsMode` 置为 `true` 后，面包屑只渲染了一段**静态文本**，没有任何可点击的关闭/返回元素：

```352:352:fanbox-1.11.2/public/app.js
  if (state.skillsMode) { bc.innerHTML = `<span class="crumb last">Skills 透视</span>`; return; }
```

同时：
- `skillsView.show()` 进入前**不推历史**，`goBack()` 可能无处可回
- **Escape 键**没有退出 skillsMode 的分支
- 退出 skillsMode 的唯一路径是调 `navigate()` 跳到某个目录（依赖侧栏可见且有可点击项目）

## 修复方案（3 处改动，均在 [app.js](fanbox-1.11.2/public/app.js)）

### 1. 进入前推历史

`skillsView.show()` 第 3580 行，进入 skillsMode 前把当前 `state.cwd` 压入 `state.history`，确保 `goBack()` 始终有目标。

```javascript
// 在 state.skillsMode = true 之前加一行
if (state.cwd) state.history.push(state.cwd);
```

### 2. 面包屑加关闭按钮

第 352 行，在 `Skills 透视` 文字后追加一个 `x` 按钮，点击执行 `goBack()` 或回退到 `state.cwd`：

```javascript
if (state.skillsMode) {
  bc.innerHTML = `<span class="crumb last">Skills 透视</span><span class="crumb sk-close" title="关闭">✕</span>`;
  bc.querySelector('.sk-close').onclick = () => {
    state.skillsMode = false;
    render();
    renderStatusbar();
  };
  return;
}
```

由于第 1 步已推过历史，这里直接恢复 `skillsMode = false` 并重新渲染即可，`state.cwd` 和 `state.entries` 还保留着上一次目录的数据。

### 3. Escape 退出 skillsMode

键盘事件处理器（约第 2364-2368 行），在现有 Escape 分支链的**前面**插入 skillsMode 判断：

```javascript
if (e.key === 'Escape' && state.skillsMode) {
  e.preventDefault();
  state.skillsMode = false;
  render();
  renderStatusbar();
  return;
}
```

放在 `previewMax` 检查之前（第 2364 行前），因为 Skills 透视是全屏视图，优先级应高于预览面板。

## 不改的部分

- `recentMode` 也有类似问题（面包屑无关闭按钮），但用户没提，不顺手改
- 后端 `/api/skills` 接口无需变动
- CSS 不需要新增样式——`.crumb` 已有 cursor:pointer 和 hover 效果
