# 项目分离与桌面应用封装

## 当前问题

根目录混合了三套代码（React 前端、Express 后端、Tauri 桌面），文件平铺难以区分哪些属于网页端、哪些属于桌面端。

## 目标结构

根目录只保留两个子项目文件夹 + 共用说明：

```
north-america-trend-digest-master/
├── web/                          (网页端：前端 + 后端 API)
│   ├── src/                      (React 前端)
│   │   ├── App.jsx
│   │   ├── main.jsx
│   │   └── styles.css
│   ├── server/                   (Express 后端)
│   │   ├── index.js
│   │   ├── sources.js
│   │   ├── aiDigest.js
│   │   └── archive.js
│   ├── index.html
│   ├── vite.config.js
│   ├── package.json
│   ├── .env.example
│   └── DEPLOYMENT.md
├── desktop/                      (桌面小软件，已有结构不动)
│   ├── src/
│   │   ├── index.html
│   │   ├── widget.js
│   │   └── widget.css
│   ├── src-tauri/
│   │   ├── src/lib.rs

├── .gitignore
└── README.md
```

## 改动清单

### 1. 创建 `web/` 并迁移网页端全部文件

移动：
- `src/` -> `web/src/`
- `server/` -> `web/server/`
- `index.html` -> `web/index.html`
- `vite.config.js` -> `web/vite.config.js`
- `package.json` -> `web/package.json`
- `package-lock.json` -> `web/package-lock.json`
- `.env.example` -> `web/.env.example`
- `DEPLOYMENT.md` -> `web/DEPLOYMENT.md`

### 2. 修复 `web/` 内部路径

`web/server/index.js` 第 34 行 distPath 当前为 `path.resolve(__dirname, "../dist")`，迁移后相对路径不变（server 和 dist 仍在同一个 web/ 下），无需改。

`web/vite.config.js` proxy 指向 `http://localhost:5050`，无需改。

`web/package.json` scripts 中的 `server/index.js` 路径无需改（相对于 web/ 根）。

### 3. 清理根目录残留

- 删除 `dist/`（构建产物，将来由 `web/dist/` 替代）
- 删除 `node_modules/`（由 web/ 内独立 install）
- 删除根目录的 `package-lock.json`（已移入 web/）
- 根 `.gitignore` 精简为：

```
node_modules/
dist/
.env
data/archive/*.json
.DS_Store
```

### 4. 根目录 README.md

替换为简要说明，指向两个子项目：

```markdown
# North America Trend Digest

北美趋势日报 — 双端项目。

## 子项目

| 目录 | 用途 | 启动 |
|------|------|------|
| `web/` | 网页端（React 前端 + Express API） | `cd web && npm install && npm run dev` |
| `desktop/` | 桌面小软件（Tauri 挂件） | `cd desktop && npm install && npm run dev` |

## 桌面端配置

`desktop/config.json` 中的 `apiBaseUrl` 指向已部署的网页端服务地址。
```

### 5. `desktop/` 不动

桌面端已经是自包含结构：
- 通过 `config.json` 中的 `apiBaseUrl` 连接远程服务器
- Rust 端用 `reqwest` 发起 HTTP 请求，具备完整网络能力
- 构建命令：`cd desktop && npm run build`

## 构建验证

- 网页端：`cd web && npm install && npm run build`
- 桌面端：`cd desktop && npm install && npm run build`，产物在 `desktop/src-tauri/target/release/bundle/`
