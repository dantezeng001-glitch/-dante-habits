# 范围选择交互重做

基于现有 `app.py` + `proofreader/*` + `ui/*` 增量改造。核心改动在前端；后端 `run_proofread` 入参不变（前端把"文档×范围"拍平成原扁平条目）。

## 数据模型变化（`ui/app.js`）
从"扁平条目（文件+sheet+范围）"改为"文档 → 多个范围"：
- `S.baselineDocs = [doc]`、`S.targetDocs = [doc]`；`doc = {id, path, name, size, sheets[], missing, ranges:[rangeItem]}`。
- `rangeItem = {id, sheet, range, keyCol, validated, _feedback, columns}`。
- `buildPayload()` 把每个 doc 的每条 range 拍平成 `{path, sheet, range, key_col}`，拼成 `baselines/targets` 扁平数组 —— 后端 `app.py` `_run_proofread` 不改。

## 迭代 1：步骤1 只选文档
- `ui/index.html` 步骤1：母本/目标各是"文档列表 + 添加文档"，去掉 sheet、范围、"+另一个sheet"。条目只显示文件名/大小/sheet 数 + 删除/重选。
- `ui/app.js`：`addDocViaDialog(group)` 选文件→拉 `list_sheets`→push doc（不预设 sheet/range）。

## 迭代 2：步骤2 给文档加多个范围
- `ui/index.html` 步骤2：先放"关系/配对/维度"紧凑区（上移，避免被一堆范围卡挤到底部），再放范围区。
- `ui/app.js` `renderStep2()`：按"母本文档 / 目标文档"分组；每个文档一个面板，标题=文件名，内含其 `ranges` 列表 + "添加范围"按钮。文档首次进入步骤2 自动建一条范围。
- 每条范围卡：sheet 下拉 + 范围只读显示 + "选择区域"按钮（开模态）+ 关键列下拉（仅按关键列配对时）+ 已选行列数绿勾/未选红标 + 删除范围。
- 局部刷新：切换 sheet/选完区域只更新该范围卡，不整页重建，避免丢状态。

## 迭代 3：大模态区域选择器（替换内嵌预览）
后端新增：
- `proofreader/scope.py` 加 `load_sheet_grid(path, sheet, max_rows=3000)`：返回整张已用区域（`col_letters` + 带绝对行号的 rows），超大截断并回传 `truncated`。
- `proofreader/excel_reader.py` `used_range` 改稳：只读模式 `max_row/max_column` 对部分 sheet 不准（截图里范围变 `A1:A1` 的根因），改用 `calculate_dimension()` 校正或回退扫描，取真实已用区域。
- `app.py` 暴露 `load_grid(path, sheet)`。

前端模态（`ui/index.html` 加模态容器 + `ui/app.js` + `ui/style.css`）：
- 点"选择区域"→打开占满窗口的模态，调 `load_grid` 渲染大表：列头=列字母吸顶、首列=绝对行号吸左、整体可横竖滚动（尺寸固定，不随选区变化，解决"选完看不见内容"）。
- 鼠标拖选单元格高亮，顶部实时显示当前选区 A1（如 `C7:F60`）；提供"全选已用区域"和手填范围输入兜底；底部"确定/取消"。
- 确定→写回该 `rangeItem.range`，关模态，`refreshScope(rangeItem)` 校验 + 取列头供关键列。

## 迭代 4：会话保存/恢复适配新结构
- `ui/app.js` `collectSession()/restoreSession()` 按 `docs(含 ranges)` 存取。
- `app.py` `load_session()` 的缺失标记改为按文档 `path` 标 `missing`（当前是按扁平条目）。

## 其他反直觉点（我主动提出，纳入本次一并修）
- 范围默认 `A1:A1` 且只看到一个"中文"格 → 由 `used_range` 修复 + 模态默认选中整个已用区域解决。
- 内嵌预览只在范围有效时才出现、又被 `max-height:240` 压成小框、框选后卡片重渲染跳动 → 预览整体移入大模态，范围卡只读显示结果。
- 关系/配对/维度被排在所有范围卡之后，多范围时要滚很久 → 上移到步骤2 顶部。
- "已用区域"按钮语义弱 → 卡片上改为"选择区域"主按钮；"全选已用区域"放进模态。
- 缺少"选好了没"的状态 → 每条范围卡显示"已选 N 行 × M 列"绿勾，未选范围红标并阻止进入校对。
- 步骤2 顶部加汇总："母本 X 个范围 / 目标 Y 个范围"。
