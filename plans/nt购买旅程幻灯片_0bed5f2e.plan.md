# NT 北美购买旅程可视化幻灯片

## 交付物

单个 HTML 文件（覆盖写入 `NT-购买旅程全景.html`），横向翻页，浏览器打开即用。内嵌 CSS + JS（含图表库），无需外部依赖。

## Redesign 要解决的 5 个核心问题

1. **信息密度低 → 每页塞满可用数据**：从源报告补充遗漏数据点，消灭无意义留白
2. **旅程链条形同虚设 → 放大为视觉脊柱**：节点改为 28-32px 圆形 + 粗连线 + 阶段标签，当前节点做脉冲动画
3. **视觉层级扁平 → 引入深色章节页 + 大数字锚点**：借鉴健身分析的设计语言，深色反转页做呼吸节点，关键数字 42-56pt
4. **图表默认风格 → 定制化图表**：加大 barWidth、定制颜色梯度、去掉不必要的网格线、图表占满分配空间
5. **源数据遗漏 → 补充关键数据**：产品满意度明细、滤噪满足度按场景、性别/年龄 NPS 分化、运动子场景分化、未替代人群细节

## 核心叙事：旅程链条贯穿始终

每一页顶部或侧边固定一条**6 节点链条**：

```
认知 → 兴趣 → 评估 → 购买 → 使用 → 推荐
```

当前页对应的节点高亮（橙色放大 + 呼吸动画），其余节点灰色缩小。翻页时链条做平滑过渡动画，形成"沿着旅程走"的叙事感。所有数据和洞察严格挂在对应节点下，不跳跃。

## 内容结构（约 12 页）

### P1 封面（深色底）

- 大标题 56pt + 橙色装饰条
- 底部 6 个数据卡片横排：男性 85% / 均龄 48.7 / 收入 $132K / 拉新 19.81% / NPS 63.46% / N=520
- 链条首次完整露出，6 节点均为中性态，尺寸 28px，位于页面上方醒目位置
- 副标题一句话定位人群："中年高收入、重品质、追新技术的核心用户"

### P2 认知 + 兴趣（链条第 1-2 节点亮起）

- 左半：第一触点渠道分布条形图（新/老/观望三类用户对比），加大 barWidth，图表占满
- 右半：Top 5 卖点柱状图，开耳滤噪 29.37% 用橙色突出
- 底部三栏：① 研究渠道一致性 ② 纯新用户 Top 3 吸引点（含数字） ③ 定性洞察（"开放式耳机里的滤噪"心智）
- **新增数据**：纯新用户转化动机 36.9% "想尝试耳挂"

### P3 评估（链条第 3 节点亮起）

- 上半：新用户 vs 老用户顾虑左右对比（各含 Top 3 + 差异点 + 原因解释）
- 中部：4 个大数字卡横排（$167 / $179 / 37人 / 42%），字号 36-42pt
- 下部：3 个聚类画像卡片横排，每张含人数 + 关键标签
- **新增数据**：滤噪预期分布图（42% 减少部分噪音 / 61% 认为弱于降噪 / 仅 1.54% 完全不清楚）

### P4 购买（链条第 4 节点亮起）

- 左半：购买原因分组柱状图（新/老/观望），图表占满
- 右半：纯新用户来源数据块（60-70% 入耳 / 17.5% 耳挂 / 7.8% 非耳挂开耳）
- 底部：产品线对比表（NT/THK/UCS/BOS/CWS），NT 行高亮
- 底部洞察条：全产品线均龄、收入、男性占比三项最高

### P5 使用·场景（链条第 5 节点亮起）

- 左半：场景 NPS 柱状图（办公/通话/放松/居家/轻运动/健身/轻松跑/户外跑/通勤/嘈杂），用绿→黄→红色阶
- 右半上：滤噪使用动机数据块（55% / 50% / 23% / 17%）
- 右半下：场景差异化动机 4 行（办公=专注 / 通话=沟通质量 / 居家=沉浸 / 运动=习惯）
- **新增数据**：① 男性 NPS 65.7% vs 女性 59.7% ② 高 NPS 年龄段 31-35 / 46-50 ③ 运动子场景分化（室内健身 > 轻松跑 > 户外跑）
- 底部洞察条：心智 ="我要听得更舒服"，不是"听不清被迫开"

### P6 使用·滤噪满足度（仍在第 5 节点）

- 左半：滤噪满足度按场景堆叠条形图（完全满足 / 很大程度 / 中等 / 较小 / 完全不满足）
- 右半：不满足场景 Top 5 列表（开放道路通勤 52.1% / 慢速骑行 / 嘈杂通勤 / 公共休闲 / 长途通勤）
- **新增数据**：完全满足率明细——放松 45.8% / 安静通勤 41.7% / 通话会议~37% / 嘈杂通勤 28% / 长途通勤 26.5%
- 底部洞察：用户期望滤噪在降噪、环境感知、安全感之间取得平衡

### P7 使用·替代（仍在第 5 节点）

- 左半：替代率横向条形图（入耳运动 80% / 骨导运动 75% / 耳挂运动 72% / 入耳办公 70.8%），barWidth 加大
- 右半：3 段用户引言（Brian / Richard / Lupearelis），紧凑排列
- 底部洞察条：滤噪用户替代率 > 非滤噪用户 → 滤噪不仅拉新，还锁留存
- **新增数据**：NT 机会场景定义（轻噪声+环境感：餐厅/骑行/遛狗/办公）vs 不适合场景（飞机火车仅 55%）

### P8 推荐 + 满意度（链条第 6 节点亮起）

- 左上：NPS 大字报 63.46%（56pt），旁边小字对比 UCS 77.5% / CWS 69.3%
- 左下：推荐 Top 3 vs 不推荐 Top 3，左右对比块，绿/红顶边
- 右半：产品满意度雷达图（蓝牙连接/音质/外观/便携 = 高分；按键触控 = 明确短板）
- **新增数据**：① 产品满意度明细（蓝牙连接、音质、外观便携 = 均值高 + 5 分占比高）② 按键触控 1-3 分偏高（第一优先级短板）③ 抱怨集中在单键多功能
- 底部：未替代人群警示行（N=71 / NPS 18.31% / 25%贬损 / 核心不满：滤噪>佩戴>音质>漏音）

### P9 全链路回顾（深色底，链条全部亮起）

- 链条 6 节点全部橙色亮起，每个节点下方一个关键数字
- 4-6 个大数字卡片横排（29.37% / -$82 / 70-80% / 55% / 63.46%）
- 中部一句话定位：NT = 轻噪声 + 环境感并存场景的开放式升级选项
- 底部表格：NPS 对比 + 优势维度 + 短板维度
- 滤噪全链路贯穿逻辑线：兴趣触发 → 购买杠杆 → 替代驱动 → 流失信号

### P10 营销投入方案（链条变为决策分支）

- 7 个营销模块卡片（PR/KOL/官网/DM/社媒/EDM/线下），4+3 网格排列
- 每张卡片含：旅程阶段标签 + 策略要点 + 数据依据
- 优先级色标：建议优先(橙) / 中等(灰) / 选择性(浅灰)
- 底部两栏：统一信息 + 谨慎建议

## 视觉系统 Redesign

### 设计语言（对齐健身分析那份的水准）

- **旅程链条**：节点改为 24-28px 圆形 + 2px 粗连线，当前节点 CSS pulse 动画，已过节点实心填充
- **大数字**：关键指标 42-56pt，monospace 字体，橙色
- **深色反转页**：P1 封面 + P9 全链路回顾用深色底（#050505），制造节奏感
- **卡片层级**：重要卡片用橙色顶边 3px + 白底；次要卡片用 #F5F5F5 底；引用块用橙色左边框 + #FFF5F0 底
- **字号体系**：标题 28-32pt / 数据标签 12-14pt / 正文 11-12pt（全面提升，消灭 9pt）

### 图表定制

- barWidth 提升到 14-20px
- 去掉默认网格线（仅保留 y 轴参考线）
- 颜色梯度：橙色主数据 / 灰色对比数据 / 绿→黄→红色阶用于 NPS
- 图表容器 padding 压缩，让图表占满分配空间

### 技术栈

- ECharts 5.4（图表）
- 纯 CSS 纵向滚动 + 键盘导航（复用现有方案）
- CSS 自定义旅程链条（纯 flexbox + 圆形节点 + 线段）
- 单文件，CDN 引入 ECharts
