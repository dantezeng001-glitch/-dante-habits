# NT 北美购买旅程可视化幻灯片

## 交付物

单个 HTML 文件，横向翻页，浏览器打开即用。内嵌 CSS + JS（含图表库），无需外部依赖。

## 核心叙事：旅程链条贯穿始终

每一页顶部或侧边固定一条**6 节点链条**：

```
认知 → 兴趣 → 评估 → 购买 → 使用 → 推荐
```

当前页对应的节点高亮（橙色放大 + 呼吸动画），其余节点灰色缩小。翻页时链条做平滑过渡动画，形成"沿着旅程走"的叙事感。所有数据和洞察严格挂在对应节点下，不跳跃。

## 内容结构（约 12 页）

### P1 封面 + 人群锚点

- 标题：NT 北美购买旅程全景
- 底部一行人群速写：男性 85% · 均龄 48.7 · 均收入 $132K · 拉新率 19.81%
- 链条首次完整露出，6 节点均为中性态

### P2 认知（链条第 1 节点亮起）

- 标题结论：官方渠道仍是第一触点，但媒体评测决定下一步
- 渠道分布条形图（新/老/观望三类用户对比）
- 关键洞察：纯新用户更依赖朋友推荐和媒体

### P3 兴趣（链条第 2 节点亮起）

- 标题结论：开耳滤噪是 NT 最强磁铁（29.37%）
- Top 3 卖点柱状图 + 新老用户差异标注
- 定性佐证：用户说的是"开放式耳机里的滤噪"，不是单独"滤噪"

### P4 评估（链条第 3 节点亮起）

- 标题结论：新老用户顾虑截然不同
- 左右对比：新用户怕嘈杂听不清 vs 老用户怕滤噪不够好
- 价格锚点大字报：无滤噪 → 仅愿付 $167（售价 $249）

### P5 购买（链条第 4 节点亮起）

- 标题结论：新用户因好奇入场，老用户因信任升级
- 购买原因分组柱状图（新/老/观望）
- 关键杠杆：滤噪是从"想买"到"掏钱"的临门一脚

### P6-P7 使用（链条第 5 节点亮起，跨 2 页）

**P6 场景全景**
- 场景使用频率 × 满意度矩阵（气泡图或热力图）
- 高 NPS 场景：办公学习、通话会议、放松休息
- 低满足场景：嘈杂通勤、长途通勤

**P7 滤噪驱动使用**
- 环形图：追求更好体验 55% / 不想听外界 50% / 习惯开启 23%
- 关键判断：滤噪心智 ="我要听得更舒服"，不是"我听不清被迫开"
- 场景差异小表格（办公=专注、通话=沟通质量、居家=沉浸、运动=习惯）

### P8 使用·替代（仍在第 5 节点）

- 标题结论：NT 在核心场景对入耳形成碾压级替代
- 替代率对比条形图：入耳运动 80%、入耳办公 70.8%、耳挂 72%、骨导 75%
- 底部洞察：滤噪用户替代率显著高于非滤噪用户 → 滤噪不仅拉新，还锁留存

### P9 推荐（链条第 6 节点亮起）

- NPS 大字报：63.46%
- 推荐 Top 3：音质 / 可以听清外界 / 滤噪
- 不推荐 Top 3：嘈杂听不清 / 滤噪效果差 / 操控不便

### P10 推荐·流失风险（仍在第 6 节点）

- 未替代人群警示：N=71，NPS 仅 18.31%，25% 贬损
- 核心不满差异：滤噪性能 > 佩戴体验 > 音质 > 音量漏音

### P11 全链路总结（链条全部亮起）

- 旅程链条从灰色逐节点变亮的动画回顾
- 每个节点下方一行核心数字
- 一句话定位：NT 的机会 = 轻噪声 + 环境感并存场景的开放式升级选项

### P12 投入方向（链条变为决策树分支）

- 链条末端分叉为 3 条投入方向：
  - 继续加注：办公/通话/室内健身场景渗透
  - 优先修复：操控体验 → 复杂环境滤噪
  - 谨慎试探：强降噪场景（通勤/飞机）不做主攻

## 可视化技术选型

- **图表**：ECharts（轻量、中文友好、支持环形图/柱状图/雷达图/热力图）
- **流程图**：CSS + SVG 手绘旅程地图（比 mermaid 更美观可控）
- **翻页**：Swiper.js 或纯 CSS scroll-snap
- **风格**：参考 Shokz 品牌色（橙色 #FF6600 为主色），深色背景 + 白字 + 橙色高亮，数据大字报风格

## 设计原则

- 每页一个核心判断（标题即结论）
- 数据必带基准/对比（不出现孤立百分比）
- 流程图贯穿全片，当前阶段高亮，其余灰化
- 关键数字用大字报呈现（48px+），辅以简短解读

## 数据来源

全部数据来自 [`NT 北美上市后报告.md`](NT 北美上市后报告.md)，不编造数据。报告中有图片链接的数据点，使用报告文字描述中的数字重建图表。
