# Persona Weight Presets

集中管理所有人群权重预设，并把每个预设背后的完整推理链作为 audit trail 沉淀下来。

**使用规则**：

1. 评估前先确认目标场景，从下方 5 套预设中选择 / 自定义。
2. 调研直接来源（默认预设）权重不应手动覆盖，应等待新调研。
3. 我的判断类预设（其余 4 套）按各自的"修改 checklist"维护。
4. 自定义权重必须附"调权理由"，用于最终报告内 cite。

**全景概览**：

| 预设 | 4 维权重（科技/跑男/颜值/开放） | 数据性质 | 适用场景 |
|---|---|---|---|
| 默认（北美总盘） | 0.218/0.316/0.163/0.303 | 调研直接来源 | Shokz 整体用户基础评估 |
| Costco 渠道 | 0.15/0.20/0.30/0.35 | 我的判断 | Costco 栈板/线下评估 |
| Target 渠道 | 0.13/0.20/0.35/0.32 | 我的判断 | Target 渠道内容/物料评估 |
| BOS DTC 渠道 | 0.25/0.50/0.05/0.20 | 我的判断 | BOS（OpenRun Pro 2）DTC 渠道评估 |
| SEAL 游泳人群 | 0.20/0.35/0.15/0.30 | 我的判断 | SEAL（OpenSwim Pro）游泳场景评估 |
| 自定义 | 用户输入 | 用户判断 | 上述场景都不匹配时 |

## 2. Costco 渠道 (女性主力购物者偏多)

### 权重

| Persona | Weight | vs Default |
|---|---|---|
| 科技老白男 | 0.15 | -6.8 pp |
| 骨传导跑男 | 0.20 | -11.6 pp |
| 日常颜值派 | 0.30 | +13.7 pp |
| 日常开放派 | 0.35 | +4.7 pp |
| Sum | 1.00 | ✓ |

### 数据来源

- 来源 1：`external_research/costco_user_research.md` §1.1
- 原文摘录："Most Costco shoppers are women, making up 72% of the customers. Whereas men make up the remaining 27% of the shoppers."
- 引用：GrabOn 2026 Costco Statistics, CouponZania 2026

### 性质

我的判断（基于已发布调研做的二次推断，非调研直接结论）

### 推理过程

1. **观察**：Shokz 现有用户调研 56% 男性 vs Costco 到店 72% 女性 → 显著错配
2. **调权方向**：上调女性人群（日常颜值/开放派），下调男性人群（科技老白男/骨传导跑男）
3. **每个人群的调权理由**：
   - 科技老白男 21.8% → 15%：男性 + 重技术参数，Costco 渠道决策权较弱
   - 骨传导跑男 31.6% → 20%：最大男性偏移，Costco 不是其主要购买渠道（多通过 Amazon/DTC）
   - 日常颜值派 16.3% → 30%：74% 女性人群，Costco 主力匹配度最高
   - 日常开放派 30.3% → 35%：99% 女性，但已是较高基线，边际上调

### 关键假设

- Costco 到店购物者中，主决策者 = 购物者本人（即耳机使用者就是结账者）
- 72% 女性数字保持稳定（如未来调研显示变化超过 5 pp，需要重算）
- 男性人群（科技老白男 + 骨传导跑男）在 Costco 渠道购买耳机的转化率显著低于在 Amazon/DTC

### 修改 checklist

出现以下任一情况需要重新计算：

- [ ] Costco 女性购物者占比变化超过 5 pp
- [ ] Costco 推出新会员结构（如企业会员、学生卡）显著改变人群组成
- [ ] Shokz 在 Costco 上架主打男性的 SKU（如纯运动型 BOS）
- [ ] 出现更新的 Shokz × Costco 渠道用户画像调研

## 3. Target 渠道 (style/value 心智, 偏年轻女性)

### 权重

| Persona | Weight | vs Default |
|---|---|---|
| 科技老白男 | 0.13 | -8.8 pp |
| 骨传导跑男 | 0.20 | -11.6 pp |
| 日常颜值派 | 0.35 | +18.7 pp |
| 日常开放派 | 0.32 | +1.7 pp |
| Sum | 1.00 | ✓ |

### 数据来源

- 来源：`external_research/target_user_research.md`（事实校准版）
- 事实层（有公开数据支持）：Target 品牌定位 style/value/convenience；Target 客群偏中等及以上收入 + 城市/郊区并重 + 偏年轻家庭
- 创作层（基于公开定位的二次推断）：三个 persona（晨跑白领 / 生活平衡家长 / 风格城市跑者）的年龄、收入区间、审美偏好
- 引用：Target 2024 Annual Report；Numerator / Store Brands / Chain Store Age 等第三方公开零售数据

### 性质

我的判断（**基于推定的推定**，风险高于 Costco 预设——Costco 至少有 72% 女这个硬数据）

### 推理过程

1. **观察**：Target 客群偏 style/value 心智，调性"自律但不苦行""有风格的实用升级"，与 Shokz 现有用户的 56% 男性 + 重技术参数偏好显著错位
2. **维度校准**：

   | 维度 | Target 原文 | 校准结论 |
   |---|---|---|
   | 性别 | Persona 2/3 女性略高 | 偏女但不如 Costco 极端（Costco 72%，Target 估约 60%） |
   | 年龄 | persona 覆盖 22-45 岁 | 比 Costco 35-55 主力更年轻 |
   | 调性 | 不喜竞技压迫感，喜 "achievable lifestyle" | 与骨传导跑男（运动硬核）调性错位明显 |
   | 审美 | style + value + 设计感 | 高度匹配日常颜值派 |

3. **每个人群的调权理由**：
   - 科技老白男 21.8% → 13%：Target "不喜技术堆砌、喜生活升级"，与科技老白男的 spec-driven 取向错位最严重
   - 骨传导跑男 31.6% → 20%：Target "自律但不苦行"与硬核运动取向错位；但 Persona 3 风格型城市跑者仍有部分骨传导跑男特征
   - 日常颜值派 16.3% → 35%：Target style/value 心智 + Persona 1（晨跑白领，女性审美）+ Persona 3（风格城市跑者）双重覆盖，匹配度最高
   - 日常开放派 30.3% → 32%：Persona 2 生活平衡家长（家庭采购、女性、家务/工作）高度匹配，但 Target 整体偏年轻使其上调幅度小于 Costco

### 关键假设

- Target 三个 persona 是创作推定，"基于推定的推定"风险高于 Costco 预设
- Target 客群比 Costco 更年轻、性别偏向更弱、style 心智更强
- 将来若有 Target × 耳机品类的真实调研，本预设需要整体重算

### 修改 checklist

- [ ] Target 发布新的客群结构数据（如新会员或新区域大幅扩张）
- [ ] Shokz 进入 Target 后产生真实的用户调研（首选触发条件）
- [ ] Target persona 文档本身被更新或修正

### 数据来源

- 原文摘录："亚马逊 BOS 用户标签：100 个 BOS 用户里会有 77 个带运动标签"
- 原文摘录："爱运动的 40+ 男性...重视环境感知、佩戴舒适、续航和防水"
- 原文摘录："40% 左右户外工作党（蓝领）"（次要群体，本预设未单独建模）

### 性质

我的判断

### 推理过程

1. **观察**：BOS 是运动旗舰，亚马逊用户 77% 带运动标签，核心用户为 40+ 男性多项耐力运动爱好者
2. **调权方向**：大幅上调骨传导跑男（最匹配画像），下调女性人群（女性占比仍低）
3. **每个人群的调权理由**：
   - 科技老白男 21.8% → 25%：BOS 用户也重视参数（如续航、降噪、DualPitch 技术），有部分交集，小幅上调
   - 骨传导跑男 31.6% → 50%：完全匹配 BOS 主画像（运动 + 男性 + 环境感知），最大上调
   - 日常颜值派 16.3% → 5%：BOS 用户中女性占比低，且偏家庭/通勤场景的女性不是 BOS 核心人群，大幅下调
   - 日常开放派 30.3% → 20%：女性日常人群在 BOS 不是主力，下调

### 关键假设

- BOS DTC 渠道用户结构与亚马逊用户标签数据具有可比性
- 蓝领用户（40% 左右）在四 persona 框架内不单独建模，分散到科技老白男和骨传导跑男中
- 26 年 8 月 OpenRun Air 2 上市可能改变蓝领触达策略，本预设暂未纳入

### 修改 checklist

- [ ] BOS 用户调研显示女性占比显著上升
- [ ] 26 年 8 月 OpenRun Air 2 上市后，BOS 与中端线的用户分流确定
- [ ] Shokz 加大蓝领触达投入，蓝领成为 BOS 重要细分

1. **观察**：SEAL 游泳人群性别和年龄都比较均衡，整体接近默认权重，但运动属性更强

### 关键假设

- 游泳人群的性别均衡是稳定的（调研显示 T0 大牛和 T1 健康养生游性别都接近 50/50）
- T0 与 T1 的比例在四 persona 框架内分散，未单独建模
- 铁三爱好者与跑男 persona 重叠度高，不单独建模

### 修改 checklist

- [ ] 26 年 SEAL 二代上市后用户结构变化

## 6. 自定义权重

### 输入规则

- 用户提供 4 个数字（按人群顺序：科技老白男 / 骨传导跑男 / 日常颜值派 / 日常开放派）
- 校验和 sum = 1.00 ± 0.05；偏差在 0.05 内时自动 normalize
- 偏差超过 0.05 时报错并提示重输

### 必填字段

用户提供自定义权重时必须附带：

1. **调权理由**：为什么这个场景需要偏离默认权重？
2. **数据依据**：基于哪份调研 / 文档 / 观察？
3. **关键假设**：调权依赖哪些假设？

这三项会被自动 cite 进最终评估报告。

### 性质

用户判断（user-provided weights）

### 何时使用

- 上述 5 套预设都不匹配你的目标场景
- 你有比 weight_presets.md 现有预设更可信的数据源（如刚做完的渠道调研）
- 你要做敏感性分析（如调高/调低某个人群权重看影响）
